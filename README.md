# Agência Fake · landing page

Landing page de uma agência fictícia, com apresentação de serviços e chamadas para contato.

**HTML · CSS**

## Explore o diferencial

| Ponto de entrada | O que observar |
| --- | --- |
| [Cartões de serviços](style.css) | Conteúdo alternativo e estilos dão ritmo à apresentação dos serviços. |
| [Adaptação do layout](reponsivo.css) | Os ajustes de responsividade ficam em uma folha dedicada. |

## Destaques

- Cabeçalho com navegação e seção de apresentação.
- Cartões de serviços com conteúdo alternativo.
- Folha de estilos específica para adaptação do layout.

<details>
<summary><strong>Executar e consultar</strong></summary>

### Executar localmente

Clone o projeto e sirva a pasta com um servidor estático. Com Python 3 instalado:

```bash
git clone https://github.com/Will-Ifes/agencia_fake.git
cd agencia_fake
python3 -m http.server 8080
```

Abra http://localhost:8080. Não há instalação de dependências ou etapa de build.
